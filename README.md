# Giflume

Simple video to gif converter / Простой конвертер видео в гиф

> [!NOTE]
> **Краткое описание:**  
> Простейший конвертер видео (mp4, avi, mov, mkv и т.д.) в гиф (gif)  
> Программа не имеет графического интерфейса, но имеет две вариации использования:  
> -Запуск с аргументами командной строки  
> -Запуск через консольное меню

> [!IMPORTANT]
> **Требования**  
> Python 3.7 или выше.  
> Установка зависимостей:  
> `pip install opencv-python Pillow`

---

## Запуск с аргументами:
**Синтаксис:**  
`python gс.py <входная_папка> <выходная_папка> [опции]`

## Обязательные аргументы

| Аргумент | Описание |
|----------|----------|
| `input_dir` | Папка с исходными видео |
| `output_dir` | Папка для сохранения GIF |

## Опции

| Опция | Описание | Значение по умолчанию |
|-------|----------|----------------------|
| `--fps N` | Частота кадров GIF | 10 |
| `--width N` | Ширина GIF в пикселях (высота пропорциональна) | 320 |
| `--preserve-speed` | Сохранять оригинальную скорость видео | False |
| `--optimize` | Оптимизировать размер GIF (медленнее) | False |
| `--recursive` | Обрабатывать подпапки рекурсивно | False |
| `--quiet` | Показывать только ошибки | False |
| `-h, --help` | Показать справку | |

## Примеры

**Базовый запуск**
```bash
python gс.py ./videos ./gifs
```

**Настройка качества**
```bash
python gс.py ./videos ./gifs --fps 15 --width 640 --optimize
```

**Сохранить оригинальную скорость видео**
```bash
python gс.py ./videos ./gifs --preserve-speed
```

**Обработать все подпапки рекурсивно**
```bash
python gс.py ./videos ./gifs --recursive
```

**Тихий режим (только ошибки)**
```bash
python gс.py ./videos ./gifs --quiet
```
